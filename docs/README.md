# docs/

Architecture notes, API reference, and runbooks.

The authoritative architecture lives in the **Development Architecture**
document (Linear, Proctoring team) and in [`CLAUDE.md`](../CLAUDE.md) at the
repo root. This directory holds longer-form docs as the platform grows:

- [`architecture/`](./architecture/) — architecture decision records (ADRs),
  e.g. [backend service boundaries](./architecture/0001-backend-service-boundaries.md).
- [`runbooks/`](./runbooks/) — operational procedures (environments, CI/CD,
  and more).
